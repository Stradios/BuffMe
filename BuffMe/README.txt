BUFF ME 1.3.0  -  for WoW 3.3.5a (Wrath)
========================================

Install
  1. Delete the old PallyPower folder (they would fight over the same job).
  2. Copy the BuffMe folder to  World of Warcraft\Interface\AddOns\
  3. Start the game. Right-click the minimap icon for settings; the How To tab explains everything.

Quick use
  Click the button           cast on the next person who needs a buff
  Mouse wheel over button    same, one cast per notch
  Shift / Ctrl / Alt + click specific single buff on target (paladin: Kings / Might / Wisdom, Shift+Ctrl = Sanctuary)
  Minimap icon               left: lock/unlock   right: settings   middle: paladin assignments
  Key binding / macro        Esc > Key Bindings > Buff Me   or   /click BuffMeButton

Player buttons: one per group member under the main button (right-click one as a paladin to pick that person's blessing).
Layout & Simulation tab: place the grid around the main button and preview 5/10/25/40/60-player groups.

Commands: /bm  /bm lock  /bm unlock  /bm grid  /bm sim [size]  /bm reset  /bm plan

Classes: Paladin (full auto-assignment), Priest, Druid, Mage, Warrior, Death Knight.
No external libraries; nothing else to install.
